This folder is the starting point for a new WindowCraft extension. Copy `template/` to `extensions/<id>/` and update `Cargo.toml`, `extension.json`, and `src/main.rs` for your extension. This folder is excluded from the Cargo workspace in the root `Cargo.toml` and is not added to `index.json` by `scripts/build-index.mjs`. See the root [README.md](../README.md) for the full instructions.
